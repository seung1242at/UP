# 블소 회상 런처 v1.8.1 — 링크와 경로만으로 업데이트

GitHub Releases는 그대로 사용하고 실제 패치 파일은 Google Drive 등 외부 저장소에 둘 수 있습니다.

## 관리자 입력 방법

1. [patch_links.json](../patch_links.json) 파일을 열고 GitHub의 **Edit** 버튼을 누르세요.
2. `files` 배열의 항목에서 `path`(게임 폴더 기준 설치 경로) 및 `url`(다운로드 링크)만 작성하세요.
3. `sha256`과 `size`는 **삭제/생략 가능**합니다. 단, 값이 있으면 새 런처에서도 해당 값을 검증합니다.
4. **Commit changes**로 저장하면 GitHub Actions가 최신 Releases에 `manifest.json`을 생성합니다.
5. 게임 이용자는 **v1.8.1 이상 런처**를 사용해야 검증값 없는 목록을 받을 수 있습니다.

## 예시

```json
{
  "files": [
    {
      "path": "bin64/정확한파일명.dll",
      "url": "https://drive.google.com/file/d/1MXTpeUc2LoPUWZ8_MkGC9ha3pDhyH16E/view?usp=sharing"
    }
  ]
}
```

**주의:** `정확한파일명.dll`은 예시일 뿐입니다. 구글 드라이브의 실제 파일명/확장자로 반드시 교체하세요. 위 예시를 그대로 복사하면 엉뚱한 이름으로 설치할 수 있습니다.

## 기존 항목 유지

기존 `patch_links.json`의 `localfile64.bin` 항목은 SHA-256과 크기가 포함되어 있습니다. 이전 버전 런처 사용자를 위해 **해당 항목은 유지**했습니다. 새로 등록하는 항목에만 값을 생략해도 됩니다.

## 안전/제한

- SHA-256을 생략하면 다운로드 결과의 진위를 검사하지 않습니다. ZIP 구조검사, HTTPS 사용, HTML 오류 페이지 감지, 다운로드 후 원본 백업 및 교체 전 임시 파일 사용은 그대로입니다.
- Google Drive는 파일 공유 권한이나 요청 한도 때문에 자동 다운로드가 차단될 수 있습니다. 일반 공유 URL을 런처가 다운로드 주소로 변환하지만 성공이 보장되지는 않습니다.
- Google Drive에서 내용을 바꿔도 GitHub의 버전이 자동 바뀌지 않습니다. 새 패치를 배포할 때마다 `patch_links.json`을 Commit하세요.
- 파일명, 확장자, 게임 루트 기준 경로를 정확히 입력해야 합니다.
