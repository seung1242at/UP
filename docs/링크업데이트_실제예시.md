# 외부 링크만 등록하여 블소 패치 배포하기

이 저장소는 기존 블소 런처의 업데이트 URL을 그대로 사용합니다:
`https://github.com/seung1242at/UP/releases/latest/download/manifest.json`

## 실제 등록 예시

[patch_links.json](../patch_links.json)에 이미 한 건이 등록되어 있습니다.

- 설치 경로: `contents/local/NCSoft/data/localfile64.bin`
- 다운로드 주소: 기존 GitHub Release의 `localfile64.bin` 파일 (실제로 존재하는 HTTPS 링크)
- 해시: 기존 배포 파일과 동일한 SHA-256
- 크기: 16,439,567바이트

이번 예시는 **이미 배포된 것과 동일한 파일**을 외부 링크로 참조하므로, 실제 게임 데이터가 새 버전으로 바뀌지 않습니다.

## 이후 다른 주소로 변경하려면

1. 패치 파일을 사용자가 별도로 다운로드 가능한 HTTPS 주소에 올립니다.
2. 실제 파일의 SHA-256과 파일 크기를 확인합니다.
3. GitHub [patch_links.json](../patch_links.json) → 연필 아이콘(Edit)을 눌러 `path`, `url`, `sha256`, `size`를 수정합니다.
4. **Commit changes**로 저장합니다.
5. [Actions](https://github.com/seung1242at/UP/actions)에서 `BNS auto-publish patch` 작업의 성공을 확인합니다.
6. [Releases](https://github.com/seung1242at/UP/releases)에서 최신 Release의 `manifest.json`이 생성됐는지 확인합니다.
7. 런처를 실행하면 새 패치 목록을 확인하고, 업데이트를 누르면 `url`에서 내려받아 `path`에 설치합니다.

### 파일을 추가할 때

`files` 배열에 같은 형식의 개체를 추가합니다. `path`에는 게임 설치 폴더 기준 상대 경로를 사용하세요.

### 주의

- 기존 `updates/` 폴더에 올린 파일도 계속 배포합니다. **동일 경로에 `patch_links.json` 항목이 있으면 링크 항목을 우선**합니다.
- `ClientConfiguration.xml` 등의 개인 설정 파일은 보호 대상입니다.
- 외부 URL은 **실제 파일 데이터를 직접 내려받는 HTTPS 주소**여야 합니다. Google Drive의 `/view` 페이지 링크는 그대로 사용하면 다운로드가 실패할 수 있습니다.
- 외부 파일의 내용만 바뀌어도 GitHub에서는 자동 감지할 수 없습니다. 반드시 `sha256`과 필요한 경우 `size`를 갱신하고 Commit해야 합니다.
- 파일을 등록하기 전에 배포 권한과 파일의 안전성을 확인하세요.
- 기존 릴리스에 포함된 같은 파일을 다시 다운로드하지 않도록 런처는 SHA-256을 비교합니다.
